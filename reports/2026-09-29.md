## New today (highest momentum first)

### [NVIDIA/OpenShell](https://github.com/NVIDIA/OpenShell) - Rust - 9,873 total stars (+978)
- **What it is:** OpenShell is NVIDIA's open-source runtime that sandboxes autonomous AI agents at the kernel level (Landlock LSM + seccomp BPF), letting them touch files, APIs, and credentials only within an enforced, formally-verified policy — the agent never sees the real secret. It's aimed at enterprises running agent fleets and competes with ad-hoc container/VM sandboxing and other emerging "agent safety runtime" projects.
- **Why now: Evidence** — NVIDIA officially unveiled it September 28, 2026 as part of its [Open Agent Safety Platform](https://nvidianews.nvidia.com/news/open-agent-safety-platform) (OpenShell software paired with a BlueField-4-based "Sentry" hardware monitor) at GTC San Jose, with launch partners Cisco, SAP, and Cadence, plus coverage on NVIDIA's dev blog and a same-day [Hacker News post](https://hn.algolia.com/api/v1/search?query=NVIDIA%2FOpenShell&tags=story).

### [oblien/openship](https://github.com/oblien/openship) - TypeScript - 13,544 total stars (+436)
- **What it is:** Openship is a self-hosted deployment platform that points at a git repo and automatically builds, containerizes, routes traffic to, and issues TLS certs for an app — usable from a desktop app, web dashboard, or CLI with no YAML config. It competes with hosted PaaS platforms like Railway, Render, and Coolify for teams that want their own always-on or on-demand deploy control plane.
- **Why now: Evidence** — v0.8.0 shipped September 27, 2026, adding server clusters, private networking, and multi-server application scaling, a substantial feature jump landing two days before today's trending appearance.

### [VectifyAI/PageIndex](https://github.com/VectifyAI/PageIndex) - Python - 36,714 total stars (+822)
- **What it is:** PageIndex is a "vectorless" retrieval system that indexes long documents — financial reports, legal contracts, technical manuals — as a reasoning tree an LLM navigates directly, instead of chunking them into a vector database. It's aimed at RAG developers working with complex professional documents and competes directly with embedding-based vector-DB RAG stacks.
- **Why now: Guess** — the project is over a year old (first launched on HN in April 2025 and again with 192 points in August 2025) and shows only routine commits through late September with no single new announcement found; today's burst looks more like a newsletter/roundup mention or renewed interest in vectorless RAG than one dated event.

### [t8y2/dbx](https://github.com/t8y2/dbx) - Rust - 21,620 total stars (+460)
- **What it is:** dbx is a ~15-25MB desktop/CLI/Docker database client covering 100+ databases (MySQL, Postgres, Redis, MongoDB, DuckDB, ClickHouse, etc.) with a built-in AI SQL assistant and an MCP server so coding agents can query databases directly. It competes with heavier GUI clients like DBeaver and TablePlus by positioning itself as the lightweight, AI-native alternative.
- **Why now: Evidence** — the maintainer shipped three releases in two days (v0.6.26 and v0.6.27 on September 27-28, plus a packages release), and has been actively cross-posting the project on [dev.to](https://dev.to/t8y2/dbx-an-open-source-15-mb-database-client-for-17-databases-built-with-tauri-45oe) and HelloGitHub — a self-promotion push rather than one single external trigger.

### [averygan/reclip](https://github.com/averygan/reclip) - HTML - 9,793 total stars (+114)
- **What it is:** reclip is a single-file, self-hosted web UI wrapper around yt-dlp that lets someone download video or audio from over a thousand sites with quality selection and bulk downloading. It competes with hosted "video downloader" websites and other yt-dlp front-ends like MeTube.
- **Why now:** no clear trigger found — no releases and no meaningful Hacker News or Reddit discussion turned up; the growth looks like word-of-mouth or a small blog/video mention rather than one identifiable event.
