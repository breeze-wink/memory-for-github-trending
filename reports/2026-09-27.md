## New today (highest momentum first)

### [willfaust/Madeira](https://github.com/willfaust/Madeira) - C - 690 total stars (+171)
- **What it is:** A research project that runs x86-64 Windows PC games on non-jailbroken iPhones by combining a Wine fork, FEX-Emu (x86-64→ARM64 translation) and DXMT (Direct3D 11→Metal), all inside a single Mach process. It competes with jailbreak-only emulation setups, not with any commercial product.
- **Why now:** **Evidence** — Taiwanese tech outlet [KOCPC](https://en.kocpc.com.tw/archives/25390) covered the project today under the headline "Madeira open-source project gets Cyberpunk 2077 running on phones," noting it also runs Stray, ULTRAKILL and Thumper on stock hardware with no cloud streaming. The author (started the project in March 2026) frames it as a rough research prototype, not a product launch, but the press pickup lines up with the stars-today spike.

### [mvschwarz/openrig](https://github.com/mvschwarz/openrig) - TypeScript - 632 total stars (+114)
- **What it is:** A CLI/TUI/MCP-server harness that runs Claude Code and Codex sessions together as one coordinated "rig," defined via YAML topologies (pods, edges, continuity policies) over tmux. It's aimed at developers who already run multiple coding agents and want them organized as a team rather than loose terminal panes.
- **Why now:** **Evidence** — [Show HN: OpenRig](https://news.ycombinator.com/item?id=47772935) (agent harness that runs Claude Code and Codex as one system) posted this week, with a follow-up [Show HN: a control plane for multi-agent coding topologies](https://news.ycombinator.com/item?id=48241066); front-page HN traffic lines up with the stars-today spike.

### [vectorize-io/hindsight](https://github.com/vectorize-io/hindsight) - Python - 35,383 total stars (+4,463)
- **What it is:** An agent memory system built to behave like human memory — time- and entity-aware recall, belief formation with confidence scores — positioned as a replacement for RAG/knowledge-graph memory stacks. Backed by Vectorize.io, a company with an existing hosted-database business and enterprise customers.
- **Why now:** **Evidence** — company blog post ["Introducing Hindsight"](https://vectorize.io/blog/introducing-hindsight-agent-memory-that-works-like-human-memory) announces it as newly fully open-sourced, paired with a co-authored arXiv paper (["Hindsight is 20/20"](https://arxiv.org/abs/2512.12818)) claiming state-of-the-art results on LongMemEval, independently reproduced by Virginia Tech's Sanghani Center and The Washington Post — a credible research launch, not just a repo dump. The project also just shipped a managed "Hindsight Cloud" offering.

### [debpalash/VoiceStudio](https://github.com/debpalash/VoiceStudio) - Python - 38,749 total stars (+3,060)
- **What it is:** A fully local, open-source voice toolkit — cloning, voice design, dubbing, dictation, transcription and audiobook creation across 646 languages — explicitly pitched as an ElevenLabs alternative that never sends audio off-device.
- **Why now:** **Evidence** — coverage today from [kil0bit](https://kil0bit.blogspot.com/2026/09/voicestudio-free-open-source-elevenlabs.html) ("The Free, Open-Source ElevenLabs Alternative Running 100% Offline") plus multiple other blog write-ups this week (dev.to, CoddyKit, Synapnews) tracking its rapid climb past 38k stars — a genuine viral spike, not slow organic growth.

### [dream-num/univer](https://github.com/dream-num/univer) - TypeScript - 19,884 total stars (+920)
- **What it is:** An open-source SDK for building office apps — spreadsheets, docs, slides, boards, structured-data "bases" and PDFs — in one canvas-rendered runtime, now explicitly marketed as an "Office Harness for AI Agents" with a Server SDK and AI SDK for agent-driven document work.
- **Why now:** **Evidence** — [v1.0.0 shipped September 24](https://github.com/dream-num/univer/releases/tag/v1.0.0), a major version bringing all six editors together with breaking API changes, followed by quick patch releases v1.0.1 and v1.0.2 (also Sept 24) fixing PDF import and chart rendering — an active post-launch push exactly the kind that drives a trending bump.

### [paperclipai/paperclip](https://github.com/paperclipai/paperclip) - TypeScript - 88,581 total stars (+2,527)
- **What it is:** An orchestration platform that runs teams of AI agents like a company — org charts, budgets, governance and task assignment via heartbeats and event triggers — built as a Node.js server with a React dashboard. It's the most established repo on today's list, launched in March 2026.
- **Why now:** **Evidence** — release v2026.916.1 shipped September 21 (6 days ago), following the larger v2026.916.0 (AgentMail, chat connectors, GitHub identity management); the "AI agent company" narrative keeps drawing fresh attention even months after launch, and the repo is now closing in on 90k stars.

### [InfinityLoop1308/PipePipe](https://github.com/InfinityLoop1308/PipePipe) - Shell - 6,390 total stars (+139)
- **What it is:** An independent, feature-heavy fork of NewPipe for Android — SponsorBlock, ReturnYouTubeDislike, danmaku overlays, AV1/VP9 support — for people who want a YouTube client outside Google's app and ecosystem.
- **Why now:** No clear trigger found. No fresh release, HN post, or press turned up to explain today's bump specifically; the project has been a hard fork with independent development since 2022.

### [vercel-labs/scriptc](https://github.com/vercel-labs/scriptc) - TypeScript - 5,221 total stars (+76)
- **What it is:** An experimental compiler from Vercel Labs that turns TypeScript/JavaScript into small native binaries (C, LLVM IR, WASM) with no embedded JS engine — startup around 2.4ms versus ~47ms baseline, memory down from ~100MB to ~4MB. Competes conceptually with Bun/Deno's "fast startup" pitch, but goes further by dropping the JS runtime entirely for statically-typed code.
- **Why now:** **Evidence** — active press wave this week: [InfoQ](https://www.infoq.com/news/2026/09/vercel-scriptc-node/), [Heise](https://www.heise.de/en/news/Vercel-s-scriptc-runs-TypeScript-natively-11388382.html), [Tim Anderson's IT Writing](https://www.itwriting.com/blog/12467-vercels-scriptc-is-a-typescript-to-native-compiler-how-did-we-get-here.html) and a [Hacker News thread](https://news.ycombinator.com/item?id=49063175) all cover it, driven by Vercel's name and the "no JS engine" framing.

### [rohitg00/ai-engineering-from-scratch](https://github.com/rohitg00/ai-engineering-from-scratch) - Python - 58,779 total stars (+848)
- **What it is:** A free, 500+ lesson curriculum that teaches AI engineering by having students implement algorithms (backprop, tokenizers, attention, agent loops) from scratch before using production frameworks, spanning four languages.
- **Why now:** **Evidence** — the author published a promotional write-up, ["Build It, Then Use It: How I Wrote 435 AI Engineering Lessons From Scratch"](https://dev.to/rohitg00/build-it-then-use-it-how-i-wrote-435-ai-engineering-lessons-from-scratch-5d2d), on DEV Community, and the curriculum was separately featured in DEV's ["One Open Source Project per Day"](https://dev.to/wonderlab/one-open-source-project-per-day-73-ai-engineering-from-scratch-build-ai-full-stack-skills-from-355h) series this week — matching the timing of the star bump.
