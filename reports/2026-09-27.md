# GitHub Trending - 2026-09-27

**Themes:**
- Multi-agent orchestration is the dominant category today: three of nine new repos (paperclip, openrig, hindsight) exist purely to coordinate or give memory to teams of AI coding/business agents.
- Open-source, local-first clones of paid AI products are pulling big numbers — VoiceStudio positions directly against ElevenLabs, Hindsight against managed "agent memory" SaaS.

## New today (highest momentum first)

### [willfaust/Madeira](https://github.com/willfaust/Madeira) - C - 685 total stars (+171)
- **What it is:** A research project that runs x86-64 Windows PC games on non-jailbroken iPhones by combining a Wine fork, FEX-Emu (x86-64→ARM64 translation) and DXMT (Direct3D 11→Metal), all inside a single Mach process. It competes with jailbreak-only emulation setups, not with any commercial product.
- **Why now:** **Guess** — no single article or launch post turned up, but a dozen+ forks appeared within hours and the premise (real Windows games on a stock iPhone) is inherently shareable on X/Reddit; likely a viral social post the search index hasn't caught up with yet. The author frames it explicitly as a rough research prototype, not a product launch.

### [mvschwarz/openrig](https://github.com/mvschwarz/openrig) - TypeScript - 610 total stars (+114)
- **What it is:** A CLI/TUI/MCP-server harness that runs Claude Code and Codex sessions together as one coordinated "rig," defined via YAML topologies (pods, edges, continuity policies) over tmux. It's aimed at developers who already run multiple coding agents and want them organized as a team rather than loose terminal panes.
- **Why now:** **Evidence** — [Show HN: OpenRig](https://news.ycombinator.com/item?id=47772935) posted today; front-page HN traffic lines up directly with the stars-today spike.

### [vectorize-io/hindsight](https://github.com/vectorize-io/hindsight) - Python - 35,283 total stars (+4,463)
- **What it is:** An agent memory system built to behave like human memory — time- and entity-aware recall, belief formation with confidence scores — positioned as a replacement for RAG/knowledge-graph memory stacks. Backed by Vectorize.io, a company with an existing hosted-database business and enterprise customers.
- **Why now:** **Evidence** — company blog post ["Introducing Hindsight"](https://vectorize.io/blog/introducing-hindsight-agent-memory-that-works-like-human-memory) announces it as newly fully open-sourced, paired with a co-authored arXiv paper (["Hindsight is 20/20"](https://arxiv.org/html/2512.12818v1)) claiming state-of-the-art results on LongMemEval, reproduced by Virginia Tech and The Washington Post collaborators — a credible research launch, not just a repo dump.

### [debpalash/VoiceStudio](https://github.com/debpalash/VoiceStudio) - JavaScript/Python - 38,686 total stars (+3,060)
- **What it is:** A fully local, open-source voice toolkit — cloning, voice design, dubbing, dictation, transcription and audiobook creation across 646 languages — explicitly pitched as an ElevenLabs alternative that never sends audio off-device.
- **Why now:** **Evidence** — third-party coverage today (["VoiceStudio: The Free, Open-Source ElevenLabs Alternative Running 100% Offline"](https://kil0bit.blogspot.com/2026/09/voicestudio-free-open-source-elevenlabs.html)) plus a recent [star-history](https://www.star-history.com/debpalash/voicestudio/) snapshot showing it at ~22.8k stars very recently, meaning most of its 38.7k total arrived in the last few days — a genuine viral spike, not slow organic growth.

### [dream-num/univer](https://github.com/dream-num/univer) - TypeScript - 19,867 total stars (+920)
- **What it is:** An open-source SDK for building office apps — spreadsheets, docs, slides, boards, structured-data "bases" and PDFs — in one canvas-rendered runtime, now explicitly marketed as an "Office Harness for AI Agents" with a Server SDK and AI SDK for agent-driven document work.
- **Why now:** **Evidence** — [Release v1.0.0](https://github.com/dream-num/univer/releases/tag/v1.0.0) shipped September 24 (3 days ago): a major version bringing all six editors together with breaking API changes, exactly the kind of milestone release that drives a trending bump.

### [paperclipai/paperclip](https://github.com/paperclipai/paperclip) - TypeScript - 88,532 total stars (+2,527)
- **What it is:** An orchestration platform that runs teams of AI agents like a company — org charts, budgets, governance and task assignment via heartbeats and event triggers — built as a Node.js server with a React dashboard. It's the most established repo on today's list, launched in March 2026.
- **Why now:** **Evidence** — a new release, v2026.916.1, shipped September 21 (6 days ago), and the project just crossed 81k→88.5k stars this week per recent coverage; the "AI agent company" narrative (Dealroom, StartupHub.ai) continues to draw fresh attention even months after launch.

### [InfinityLoop1308/PipePipe](https://github.com/InfinityLoop1308/PipePipe) - Java/Kotlin - 6,379 total stars (+139)
- **What it is:** An independent, feature-heavy fork of NewPipe for Android — SponsorBlock, ReturnYouTubeDislike, danmaku overlays, AV1/VP9 support — for people who want a YouTube client outside Google's app and ecosystem.
- **Why now:** No clear trigger found. The project's most recent notable release (v4.9.0) was back in April; no fresh release, HN post, or press turned up to explain today's bump specifically.

### [vercel-labs/scriptc](https://github.com/vercel-labs/scriptc) - TypeScript - 5,210 total stars (+76)
- **What it is:** An experimental compiler from Vercel Labs that turns TypeScript/JavaScript into small native binaries (C, LLVM IR, WASM) with no embedded JS engine — startup in ~2ms versus ~60ms for Node, at the cost of raw execution speed. Competes conceptually with Bun/Deno's "fast startup" pitch, but goes further by dropping the JS runtime entirely.
- **Why now:** **Evidence** — active press wave this week: [InfoQ](https://www.infoq.com/news/2026/09/vercel-scriptc-node/), [Heise](https://www.heise.de/en/news/Vercel-s-scriptc-runs-TypeScript-natively-11388382.html), and a [Hacker News thread](https://news.ycombinator.com/item?id=49063175) all cover it, driven by Vercel's name and the "no JS engine" framing.

### [rohitg00/ai-engineering-from-scratch](https://github.com/rohitg00/ai-engineering-from-scratch) - Python/TypeScript/Rust/Julia - 58,758 total stars (+848)
- **What it is:** A free, 500+ lesson curriculum that teaches AI engineering by having students implement algorithms (backprop, tokenizers, attention, agent loops) from scratch before using production frameworks, spanning four languages.
- **Why now:** **Evidence** — the author published a promotional write-up today, ["Build It, Then Use It: How I Wrote 435 AI Engineering Lessons From Scratch"](https://dev.to/rohitg00/build-it-then-use-it-how-i-wrote-435-ai-engineering-lessons-from-scratch-5d2d), on DEV Community, matching the timing of the star bump.
