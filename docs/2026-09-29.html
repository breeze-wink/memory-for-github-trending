01

NVIDIA/OpenShell

Rust★ 9,873+978 today
momentum 9.9%

OpenShell is NVIDIA's open-source runtime that sandboxes autonomous AI agents at the kernel level (Landlock LSM + seccomp BPF), letting them touch files, APIs, and credentials only within an enforced, formally-verified policy — the agent never sees the real secret. It's aimed at enterprises running agent fleets and competes with ad-hoc container/VM sandboxing and other emerging "agent safety runtime" projects.

Evidence

NVIDIA officially unveiled it September 28, 2026 as part of its Open Agent Safety Platform (OpenShell software paired with a BlueField-4-based "Sentry" hardware monitor) at GTC San Jose, with launch partners Cisco, SAP, and Cadence, plus coverage on NVIDIA's dev blog and a same-day Hacker News post.

oblien/openship

TypeScript★ 13,544+436 today
momentum 3.2%

Openship is a self-hosted deployment platform that points at a git repo and automatically builds, containerizes, routes traffic to, and issues TLS certs for an app — usable from a desktop app, web dashboard, or CLI with no YAML config. It competes with hosted PaaS platforms like Railway, Render, and Coolify for teams that want their own always-on or on-demand deploy control plane.

Evidence

v0.8.0 shipped September 27, 2026, adding server clusters, private networking, and multi-server application scaling, a substantial feature jump landing two days before today's trending appearance.

PageIndex is a "vectorless" retrieval system that indexes long documents — financial reports, legal contracts, technical manuals — as a reasoning tree an LLM navigates directly, instead of chunking them into a vector database. It's aimed at RAG developers working with complex professional documents and competes directly with embedding-based vector-DB RAG stacks.

Guess
